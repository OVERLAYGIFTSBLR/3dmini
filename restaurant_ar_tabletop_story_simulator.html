Ready-to-Deploy Template

MindAR + Three.js Tabletop QR Anchor Code

This clean single-file boilerplate anchors a 3D animated glTF model to a physical QR coaster. Replace the `.mind` target file and 3D `.glb` model URL with your own restaurant assets.

1

Image Target (.mind)

Compile your restaurant logo or QR coaster with MindAR Image Compiler to generate a lightweight 50KB tracking file.

2

Low-Poly Animated GLB

Keep 3D models under 6MB with Draco compression so it loads in under 1.5 seconds over 4G cellular restaurant WiFi.

3

Kitchen POS/KDS Sync

Hook the act selector into your POS Webhook or Firebase Realtime DB to switch animations when the kitchen status turns to 'Plating'.

<!DOCTYPE html>
<html>
  <head>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Restaurant AR Tabletop Story</title>
    <!-- 1. MindAR WebAR Library & Three.js -->
    <script src="https://cdn.jsdelivr.net/npm/mind-ar@1.2.2/dist/mindar-image-three.prod.js"></script>
    <script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/loaders/GLTFLoader.js"></script>
    <style>
      body { margin: 0; overflow: hidden; font-family: sans-serif; }
      #ar-container { width: 100vw; height: 100vh; position: relative; }
      #kds-overlay {
        position: absolute; bottom: 20px; left: 50%; transform: translateX(-50%);
        background: rgba(15, 23, 42, 0.9); color: #fff; padding: 12px 24px;
        border-radius: 999px; border: 1px solid #eab308; font-size: 14px;
        box-shadow: 0 10px 25px rgba(0,0,0,0.5); z-index: 10;
      }
    </style>
  </head>
  <body>
    <div id="ar-container"></div>
    <div id="kds-overlay">🍳 Chef Marco is grilling your order...</div>

    <script>
      document.addEventListener("DOMContentLoaded", () => {
        const startAR = async () => {
          // Initialize MindAR with your compiled Coaster .mind file
          const mindarThree = new window.MINDAR.IMAGE.MindARThree({
            container: document.querySelector("#ar-container"),
            imageTargetSrc: "https://cdn.jsdelivr.net/gh/hiukim/mind-ar-js@1.2.2/examples/image-tracking/assets/card-example/card.mind" // <-- Replace with your coaster .mind target
          });

          const { renderer, scene, camera } = mindarThree;

          // Ambient & Warm Table Spotlight
          const ambientLight = new THREE.AmbientLight(0xffffff, 0.8);
          scene.add(ambientLight);
          const dirLight = new THREE.DirectionalLight(0xfff3d6, 1.2);
          dirLight.position.set(2, 5, 3);
          scene.add(dirLight);

          // Anchor group linked to target 0 (the coaster)
          const anchor = mindarThree.addAnchor(0);

          // Load 3D Chef Character / Dish glTF
          const loader = new THREE.GLTFLoader();
          let mixer;
          
          loader.load(
            "https://threejs.org/examples/models/gltf/RobotExpressive/RobotExpressive.glb", // <-- Replace with chef_character.glb
            (gltf) => {
              const model = gltf.scene;
              model.scale.set(0.18, 0.18, 0.18);
              model.position.set(0, -0.1, 0);
              anchor.group.add(model);

              // Play 'Dance' / 'Jump' animation
              mixer = new THREE.AnimationMixer(model);
              if (gltf.animations.length > 0) {
                const action = mixer.clipAction(gltf.animations[0]);
                action.play();
              }
            }
          );

          // Start WebAR Engine
          await mindarThree.start();

          const clock = new THREE.Clock();
          renderer.setAnimationLoop(() => {
            const delta = clock.getDelta();
            if (mixer) mixer.update(delta);
            renderer.render(scene, camera);
          });
        };

        startAR();
      });
    </script>
  </body>
</html>

How Tabletop AR Stories Work

Psychology of perceived wait time

Research in hospitality operations shows that an unoccupied 20-minute wait feels like 26 minutes, while an interactive narrative reduces perceived wait time to only 10–12 minutes while elevating dessert & beverage orders.

  • Camera Mode: Click the camera button to enable your device webcam and view the animated chef sitting directly on your desk or plate.
